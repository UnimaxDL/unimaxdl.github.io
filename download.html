Safe Install Guide

How to install UnimaxDL on Android (v2.1.0 APK)

Tap Download .APK above, open the downloaded file in notifications or your Files app, allow “Install unknown apps” once when prompted by Android, and tap Install.

Windows SmartScreen “Windows protected your PC” prompt

New open-source apps without an expensive EV certificate trigger an informational check on first launch. Click More info → Run anyway to install cleanly.

macOS Gatekeeper & Linux AppImage permissions

On macOS, drag UnimaxDL to Applications, Control-click it once, and choose Open. On Linux, run chmod +x UnimaxDL-v1.0.0-linux.AppImage or toggle “Allow executing file as program”.
