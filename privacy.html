[ SPEC // 01 — DATA MINIMALISM ]

Privacy Policy

DOCUMENT REVISION: 2026.11 // STATUS: ACTIVE REGULATORY FRAMEWORK

1. User Sovereignty & Data Minimalism

UniMaxDL operates on an absolute principle of client data sovereignty. We do not sell, license, rent, monetize, or harvest user personal information. The software is constructed to operate without registration barriers: there are no accounts, user databases, login credentials, or personal profiles required to utilize any indexing feature.

2. Information We Process

When an extraction command is initiated, our servers process only the technical payloads necessary to parse and route the requested media stream:

  • Submitted Media URLs: Evaluated purely in volatile memory by our resolver backend to extract audio and video stream URLs. Submitted URLs are never permanently linked to IP addresses or visitor identities.
  • Temporary Stream Buffers: When remote platform formats require stream muxing (such as combining adaptive DASH video and audio streams), files are temporarily written to a volatile RAM disk or ephemeral temporary directory.

3. Zero Advertising & Third-Party Behavioral Tracking

Unlike conventional web extractors, UniMaxDL does not deploy cross-site behavioral tracking beacons, fingerprinting pixels, or invasive demographic profiling scripts. External ad tags are isolated to non-intrusive runtime scripts that have no access to extraction payloads.

4. Browser Local Storage (localStorage) Usage

The website utilizes modern client-side storage solely to remember user-controlled client preferences:

  • udl-theme: Preserves your selected visual deck mode (light vs dark).
  • udl-custom-endpoint: Optional custom self-hosted extractor endpoint configured by advanced users.

No authentication cookies, session trackers, or third-party tracking identifiers are placed in your browser storage.

5. Anonymized Operational Telemetry

To monitor global pipeline uptime and detect broken platform extraction extractors when upstream services alter their APIs, minimal anonymized metrics (such as target platform type, extraction status code, and latency) are aggregated via Supabase telemetry. These operational logs contain no personally identifying records.

6. Automated 30-Minute Volatile Purge

AUTOMATED BUFFER SCRUBBING: All temporary muxed files and session artifacts residing on our backend instances are automatically scheduled for permanent erasure every 30 minutes. No long-term storage or media archive is maintained.
