# Privacy Policy — UnimaxDL

**Last updated:** November 3, 2026

UnimaxDL is committed to user privacy. We believe utility tools should do their job without tracking, spying, or harvesting personal information.

### 1. No Personal Data Collected
- UnimaxDL does **not** collect your name, email address, phone number, location, or credentials.
- When running locally or using the app, your downloaded media files stay on your private device.

### 2. Anonymous Telemetry & Counters
To measure project growth, monitor platform reliability, and understand which extractors require updates, UnimaxDL may collect anonymous, non-identifiable usage statistics:
- Daily active session counts (random UUID generated per session).
- Aggregated download counts by platform domain (e.g. `youtube.com`, `tiktok.com`).
- Video format and resolution selected (e.g. `1080p`, `mp3-320`).
- Basic device information (Operating System, App Version).

No IP addresses, cookies, or persistent user profiles are stored in our analytics database.

### 3. Open Source Transparency
All source code for the Web UI, Python backend, and client applications is publicly available on GitHub under the MIT License for independent security audit.
